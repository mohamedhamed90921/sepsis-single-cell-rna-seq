# Single-Cell RNA-seq Analysis of Sepsis

## Overview

This project uses single-cell RNA sequencing (scRNA-seq) data to investigate cellular heterogeneity and immune dysregulation associated with sepsis.

The workflow is implemented in R and documented using Quarto, providing a reproducible record of the analysis, visualizations, and interpretation.

## Research Objectives

- Explore cellular heterogeneity in sepsis-related samples.
- Characterize cell populations using single-cell transcriptomic data.
- Investigate cell-type-specific gene expression patterns.
- Visualize cellular structure and explore biological patterns associated with sepsis.

## Dataset

- **GEO accession:** GSE163668
- **Source:** NCBI Gene Expression Omnibus
- **Dataset page:** https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE163668

Raw sequencing data are not included in this repository. Please refer to the original GEO record for dataset information and access.

## Analysis Workflow

The project report documents the analysis workflow, including applicable steps such as:

1. Data preparation and quality control
2. Normalization and feature selection
3. Principal component analysis (PCA)
4. Batch-effect correction using Harmony, where applicable
5. UMAP visualization and cell clustering
6. Cell-type annotation
7. Downstream analysis and visualization

Refer to the Quarto report for the specific methods and results implemented in this project.
